# 검증 가이드

수동 검증이나 여러 검증 경로를 계획에 구체적으로 적어야 할 때 사용한다.

## 검증 선택

검증은 변경 범위와 실패 비용에 맞춘다.

- 정적 구조·설정: 차이 확인, 스키마·형식 검사
- 코드 규칙: 린트, 정적 분석, 컴파일
- 계산·규칙: 승인된 자동 테스트 또는 좁은 실행
- 상태 전이·통합: 대표 시나리오 실행
- 시각 결과: 렌더 결과 비교 또는 수동 확인
- 외부 연결: 실제 진입점과 로그·응답 확인

새 테스트 생성과 기존 테스트 실행 권한은 루트 `AGENTS.md`를 따른다.
한 검증이 성공했다고 더 높은 수준의 검증까지 성공한 것으로 확대하지 않는다.

## 수동 검증 매뉴얼

수동 확인을 포함한다면 `수동 확인` 한 줄로 끝내지 말고 실행자가 그대로 따라 할 수 있게 작성한다.

- 준비 상태: 필요한 화면, 데이터, 계정, 환경과 설정
- 실행 절차: 어떤 순서로 무엇을 조작할지
- 기대 결과: 각 절차 후 무엇이 보여야 하거나 유지되어야 하는지
- 실패 신호: 어떤 상태를 실패로 볼지
- 회귀 확인: 기존에 유지되어야 하는 동작의 확인 절차
