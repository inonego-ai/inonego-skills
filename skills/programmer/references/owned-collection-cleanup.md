# 소유 컬렉션 일괄 정리

개별 `Remove`·`Release`·`Dispose`가 항목 정리와 소유 컬렉션 제거를 함께 수행하고, `All` 메서드가 같은 컬렉션 전체를 정리할 때만 적용한다.

## 권장 구조

- 공통 내부 메서드에 컬렉션 제거 여부를 나타내는 `bool`을 두고 기본값을 `true`로 한다.
- 이름은 `removeFromAcquired`처럼 실제 소유 컬렉션을 드러내게 짓는다.
- 개별 처리는 기본값으로 호출한다.
- `All`에서는 제거 여부를 `false`로 전달해 원 컬렉션을 직접 순회하고 마지막에 한 번 `Clear()`한다.
- 모든 항목의 정리를 끝까지 시도해야 한다면 항목별 예외를 수집하고, 순회를 마친 뒤 컬렉션 정리와 오류 전달을 수행한다.
- 순회 중 변경을 피하려는 목적만으로 스냅샷이나 임시 컬렉션을 만들지 않는다.

## 적용 조건

- 개별 처리의 직접·간접 호출이 순회 중인 컬렉션을 변경하지 않는다.
- 각 항목의 정리 시도가 끝나면 성공 여부와 관계없이 논리적 소유권이 종료되는 계약이다.
- 실패한 항목을 계속 소유해야 하는 계약이면 마지막에 일괄 `Clear()`하지 않는다.
- 가능성만 추측해 방어 구조를 추가하지 말고 실제 호출 흐름과 소유권 계약을 확인한다.
