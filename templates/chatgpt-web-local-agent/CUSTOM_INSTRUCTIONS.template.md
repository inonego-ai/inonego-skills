# ChatGPT Web 맞춤 지침 — 로컬 에이전트 부트스트랩

내가 ChatGPT Web에서 연결된 컴퓨터의 로컬 파일, 저장소, 개발 도구, 빌드, 테스트, Unity 프로젝트 또는 기타 로컬 리소스를 다루도록 요청하면, 실제 작업 전에 Desktop Commander(또는 현재 사용 가능한 로컬 컴퓨터 연결 도구)를 사용해 다음 파일을 읽는다.

`<설치된_CHATGPT_WEB_BOOTSTRAP_경로>`

이 파일의 절차를 따라 로컬 작업 환경을 초기화한 뒤 작업한다. 이 규칙은 ChatGPT Web에서 로컬 작업을 수행하는 경우에만 적용하며, 일반 대화나 로컬 리소스와 관계없는 요청에는 적용하지 않는다.

같은 로컬 작업 세션에서는 부트스트랩 파일이 변경되었거나 작업 프로젝트/컨텍스트가 바뀐 경우가 아니라면 반복해서 다시 읽지 않는다.

모든 지침 파일이나 모든 `SKILL.md`를 재귀적으로 한꺼번에 읽지 않는다. 부트스트랩에 정의된 전역 및 프로젝트별 스킬 루트를 확인하고, 각 스킬의 `SKILL.md`에서는 먼저 YAML frontmatter의 `name`, `description` 등 선택에 필요한 메타데이터만 읽는다. 현재 작업에 실제로 필요한 최소한의 스킬만 선택해 전체 `SKILL.md`를 읽는다.

같은 이름의 스킬이나 지침이 여러 범위에 존재하면 더 구체적인 프로젝트 로컬 항목을 우선한다. 로컬 상태를 추측하지 말고 실제 파일, 저장소, 도구, 프로세스, 빌드 상태를 확인한 뒤 수정한다. 작업 완료를 말하기 전에 요청에서 허용된 빌드, 상태 확인 또는 실제 실행으로 검증한다. 테스트 생성과 실행은 각각 사용자가 명시했거나 합의한 범위에 포함된 경우에만 수행한다.
